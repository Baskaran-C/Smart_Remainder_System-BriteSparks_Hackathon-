Adaptive Reminder Pipeline

🛡️ Rolling Limit Firewall

Strictly enforces CR-2026/11 limiting resident notifications to a maximum of 2 in any 7-day period. Failed attempts count, withheld attempts are logged.

🛰️ Location-Aware Departure

Calculates travel time between the resident's GPS snapshots and the target office. Prompts departure triggers when travel time approaches.

⏱️ Cooldown & Seen Logic

Monitors Seen/Unseen status to avoid user fatigue. Restricts updates through a 30-minute cooling firewall if the reminder was viewed.

📈 Explainable Decisions

Stores detailed decision pipeline factors (SEND, WAIT, MOVE, RECOVER, STOP, WITHHELD) and logs exact justifications to the dashboard.
